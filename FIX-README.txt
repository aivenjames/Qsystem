Qsystem fixed build - appointment date/time editing

INSTALLATION
1. Stop Apache in XAMPP.
2. Make a backup copy of your current C:\xampp\htdocs\Qsystem folder.
3. Extract this ZIP.
4. Copy the contents of the Qsystem folder in this ZIP into C:\xampp\htdocs\Qsystem and choose Replace files.
5. Start Apache and MySQL in XAMPP.
6. Open http://localhost/Qsystem/appointments.php

DATABASE
This update uses the existing qsystem database and appointments table. Do not delete your database and do not import database.sql over existing records unless you have a backup.

EDIT APPOINTMENT
Sign in as a student, open Appointments, and click Edit date/time beside a Pending, Approved, or Waiting appointment. Save changes. Rescheduling an approved/waiting appointment resets it to Pending so staff can approve the new schedule.

If you still see an error, copy the exact PHP error message (including the file name and line number) or send a screenshot. The exact message is needed to diagnose a different local configuration problem.
